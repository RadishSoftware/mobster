The standalone `mobster` command runs without Mobster for Mac. Step 2 runs a demo that needs no iPhone and no key.

## Before you begin

- macOS and [uv](https://docs.astral.sh/uv/getting-started/installation/), with `uv` and `uvx` on your `PATH`. uv manages the CLI's Python environment.
- Xcode for device operation, with your iPhone or simulator configured through [device setup](/device-setup).
- A Claude or OpenAI key for autonomous tasks. The demo needs no key; MCP clients use their own model account.

## Set up

<Steps>
  <Step title="Install the standalone CLI">
    Install the Python package in an isolated tool environment:

    ```sh
    uv tool install --python 3.12 mobster-cli
    ```

    If uv reports that its executable directory is missing from your `PATH`, run `uv tool update-shell` and open a new terminal.

    If you prefer npm, install the launcher instead. It still requires uv and downloads the same Python CLI on first use:

    ```sh
    npm install -g @radishsoftware/mobster
    ```

    Both install paths provide the `mobster` command:

    ```sh
    mobster version
    ```

    ```text Output
    mobster 0.4.3
    ```

    These registry commands require the corresponding Python and npm releases to be published.
  </Step>
  <Step title="Run the demo">
    ```sh
    mobster demo
    ```

    Mobster's agent runs one task on a scripted phone and prints each step. It makes no model calls.

    ```text Output
    ❯ Search for coffee  scripted demo: no iPhone, no model calls
      ● Opened Safari
      ● Tapped “Search”
        ⎿ Safari → screen changed
      ● Typed and submitted in “Search”
        ⎿ Safari → screen changed
      ✓ Checked the task is done
    ✓ Done  2 steps, 4.9 s
      The top result is the Coffee guide.
    ```
  </Step>
  <Step title="Check your Mac and iPhone">
    ```sh
    mobster doctor
    ```

    Each line is one check. A `✗` line needs fixing, and the arrow under it is the command that fixes it. On a Mac with its iPhone connected and no key yet:

    ```text Output
    Mobster doctor

      ✓ Python            3.12.13
      ✓ Mobster           0.4.3, installed
      ✗ Model key         none yet
                          → mobster login
      ✓ Xcode             Xcode 26.4
      ✓ iPhone tools      installed
      ✓ iPhone            iPhone 15 Pro, iOS 26.0.1, trusts this Mac (+1 more)
      ...
      ✓ Screen            unlocked
      ✓ In use            no other Mobster is using it

    1 thing to fix before your first task.  Help: https://docs.mobster.dev/troubleshooting
    ...
    ```
  </Step>
  <Step title="Save your key">
    Skip this step if you saved a key in Mobster for Mac: the command uses the same one.

    ```sh
    mobster login
    ```

    ```text Output
    Mobster's agent runs on your own Claude or OpenAI key.
    You pay them for what it uses, and the key stays on this Mac.

    Which AI do you use?
      1  Claude, by Anthropic   recommended
      2  OpenAI
    Choose 1 or 2 [1]: 1

    Get a key from the Claude Console: https://platform.claude.com/settings/keys
    Paste your Claude key (it starts with sk-ant-; it isn't shown):
    ```

    Mobster tests the key with one small request, then saves it on this Mac. Run `mobster doctor` again: its last line says `Ready for tasks.`
  </Step>
</Steps>

## Use Mobster for Mac

The [Mac app](/quickstart/mac) is a separate install with a desktop interface and its own bundled command. Choose it for the app workspace; it is not a prerequisite for the standalone CLI above.

## Run a task

Unlock your iPhone and run:

```sh
mobster run "Open Settings and tell me which iOS version this is" --execute
```

Each step prints as it happens, in the same format as the demo, then the answer. Before Mobster sends, buys, posts or deletes, it asks at the terminal: answer `y` or `n`.
