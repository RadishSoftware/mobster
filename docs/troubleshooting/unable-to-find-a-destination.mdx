You see this: `xcodebuild` prints this line when Mobster builds its helper (WebDriverAgent, the `WebDriverAgentRunner` scheme) for your iPhone, during setup or a refresh.

## Why it happens

Xcode found no destination it can build for. The lines under it, headed `Ineligible destinations`, say why. Two causes are recorded in Mobster's tests:

| The line under it ends | The cause |
|---|---|
| `error:Developer Mode disabled To use … for development, enable Developer Mode in Settings → Privacy & Security.` | Developer Mode is off on the iPhone. |
| `error:iOS 26.4 is not installed. To use with Xcode, first download and install the platform` | Your Xcode doesn't have the iOS version your iPhone runs. |

A locked phone, an unplugged cable or a Mac the phone doesn't trust yet also leave Xcode without a destination.

## Fix

1. Unlock the iPhone, keep it connected and tap **Trust** if it asks.
2. If the line under it says Developer Mode, follow [Developer Mode disabled](/troubleshooting/developer-mode-disabled).
3. If it says an iOS version is not installed, open Xcode and let it finish installing: **Settings › Components › iOS**. Update Xcode if your iPhone's iOS is newer than it.
4. Build again from Mobster for Mac, or run `mobster doctor`.

## Check it worked

`mobster doctor` prints a line for each of these, with the fix under any line marked `!` or `✗`.
