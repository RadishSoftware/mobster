Mobster for Mac gives an agent your iPhone. Type a task, watch every tap in a live view of the phone, and approve anything it would send, buy, post or delete. Mobster CLI, the engine inside it, is free and open source: try it from Terminal, give it to the coding agent you already use, or run your app's checks with `mobster test` on simulators and on the iPhone on your desk.

## What you can ask

- **“Find my last message from Kate Bell,”** then **“Reply that I'm running 10 minutes late.”** Mobster works in your apps, signed in as you, including ones with no API. The follow-up knows who you mean.
- **“Restyle the paywall, then check it still shows three plans.”** Your coding agent can see the app it just changed. The pass or fail comes from what's on screen, never from a model, so the verdict costs no model call.
- **`mobster test` on every pull request.** Checks find buttons by name, not by position on screen, and each run writes JUnit and an HTML report for CI.

## How it works

Mobster runs on your Mac and drives the iPhone over a USB cable. It reads each screen the way VoiceOver does, as buttons and text with names, so it taps “Send” by name. Before it sends, buys, posts or deletes, it stops and shows you the exact action. Mobster's agent runs on your Claude or OpenAI key, and no Mobster server sits in between.

It can't get past Face ID or your passcode, and it needs your iPhone plugged in and unlocked.

## Start free with the CLI

<CodeGroup>
```sh Install script
curl -fsSL https://mobster.dev/install.sh | sh
```

```sh Homebrew
brew install radishsoftware/tap/mobster
```
</CodeGroup>

Then run `mobster --demo` to watch a task on a scripted phone. No iPhone or key needed.
