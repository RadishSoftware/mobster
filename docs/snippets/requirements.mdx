| | Tasks on your iPhone | Checks on a simulator |
|---|---|---|
| Mac | Apple silicon, macOS 13 or later | Apple silicon, macOS 13 or later |
| Mobster | Mobster for Mac | Mobster for Mac, for its `mobster` command |
| Xcode | Free from the App Store, signed in to an Apple Account (a free one works). Setup offers it | An iOS Simulator runtime. Mobster is tested with Xcode 26.4 |
| iPhone | Developer Mode on, and a USB cable that carries data | None |
| Model provider | Your own key, or a plan you already pay for (Codex, Claude Code, Gemini CLI and others). You pay them directly | None for launch-only checks and your coding agent's own loop. Steps that Mobster's agent runs need a key |
| Account | A Mobster account (Apple, Google, GitHub or an email code) with a plan or the 7-day free trial | None |

Mobster runs on macOS 13 or later. To set up your iPhone and to build and test your own app, you need the macOS your Xcode version needs ([Apple lists it on its Xcode page](https://developer.apple.com/support/xcode/)). Voice needs macOS 26 or later.
