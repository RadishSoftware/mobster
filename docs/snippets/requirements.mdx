| | Mobster for Mac | Mobster CLI |
|---|---|---|
| Mac | Apple silicon, macOS 13 or later | Apple silicon, macOS 13 or later |
| Xcode | Free from the App Store, signed in to an Apple Account (a free one works). Setup offers it | The same, for an iPhone. For checks, an Xcode with an iOS Simulator runtime; Mobster is tested with Xcode 26.4 |
| iPhone | Developer Mode on, and a USB cable that carries data | The same, for tasks on a phone. Checks can run on simulators alone |
| AI account | Your own Claude or OpenAI account and key. You pay them directly | Only for Mobster's agent. Launch-only checks and your coding agent's own loop need none |
| Voice | macOS 26 or later | Not in the CLI |
| License | A Mobster for Mac license | None: free and open source under MIT |

Your Mac also needs the macOS version your Xcode needs: Apple lists it on [Xcode's support page](https://developer.apple.com/support/xcode/).
