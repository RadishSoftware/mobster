Each endpoint below is `GET /v1/<app>/<thing>` on the App API and the MCP tool `<app>_<thing>` in Mobster's MCP server, with the same parameters and the same answer. `GET /v1/screen` (`read_screen`) reads the screen in front, in any app, into the fields you name. Every endpoint only reads: it may tap, type and scroll to reach the screen and read it, and never likes, follows, comments, sends, posts, buys or deletes. [App API](/app-api) shows how to call it, and [MCP server](/mcp-server#app-tools) how an agent does.
