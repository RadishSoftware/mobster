The generated workflow runs the standalone `mobster-cli==0.4.3` package through uv. It needs macOS, Xcode and an iOS Simulator runtime. The Mac app is not required.

Xcode Cloud runs a script after a build when the script is named `ci_post_xcodebuild.sh` in a `ci_scripts` folder at the root of your repository. `mobster ci init` writes that script. [CI](/ci) has the parts every host shares.

## Set it up

```sh
mobster ci init --host xcode-cloud
```

It writes `ci_scripts/ci_post_xcodebuild.sh`, marked executable, and prints what's left: add `ANTHROPIC_API_KEY` for checks with steps as a secret environment variable of your Xcode Cloud workflow, commit the file and open a pull request.

```sh ci_scripts/ci_post_xcodebuild.sh
#!/bin/sh
# Mobster checks after Xcode Cloud builds a pull request (https://docs.mobster.dev/ci/xcode-cloud).
# Add ANTHROPIC_API_KEY as a secret environment variable for checks with steps.
set -eu
if [ -z "${CI_PULL_REQUEST_NUMBER:-}" ]; then
  echo "This build isn't for a pull request, so Mobster tested nothing."
  exit 0
fi
brew install uv
uvx --python 3.12 --from mobster-cli==0.4.3 mobster sim doctor --fix
status=0
uvx --python 3.12 --from mobster-cli==0.4.3 mobster ci run || status=$?
uvx --python 3.12 --from mobster-cli==0.4.3 mobster ci comment || true   # Xcode Cloud has no comment token; the verdict is in this log
exit "$status"
```

The script exits with the checks' exit code, so a failed check fails the Xcode Cloud build. The target branch comes from `CI_PULL_REQUEST_TARGET_BRANCH`. Xcode Cloud posts no comment on the pull request through Mobster: the verdict and the report's location are in the build log, and `.mobster/ci/comment.md` holds the comment.

## Credentials

Launch-only checks need no model key. Set `ANTHROPIC_API_KEY` for checks that use Smart. The standalone CLI requires no Mobster account or CI token. If you supply `MOBSTER_CI_TOKEN`, `mobster ci doctor` still validates it. App-bundled commands retain their plan and token checks.

## What this runner doesn't do

A hosted Mac has no iPhone, so the checks run on simulators. To test on a phone, use [a Mac of yours](/ci/mac-runner).
