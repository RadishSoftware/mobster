The generated workflow runs the standalone `mobster-cli==0.4.2` package through uv. It needs macOS, Xcode and an iOS Simulator runtime. The Mac app is not required.

Codemagic builds on macOS machines it hosts. `mobster ci init --host codemagic` writes the workflow. [CI](/ci) has the parts every host shares.

## Set it up

```sh
mobster ci init --host codemagic
```

It writes `codemagic.yaml`. When that file exists, it leaves it as it is and writes the workflow to `.mobster/hosts/codemagic.yaml` for you to merge. Then put `ANTHROPIC_API_KEY` for checks with steps in a variable group named `mobster` (Codemagic › Teams › Global variables and secrets), commit the file and open a pull request.

```yaml codemagic.yaml
# Mobster checks on every pull request, on a Codemagic Mac (https://docs.mobster.dev/ci/codemagic).
# Put ANTHROPIC_API_KEY in a variable group named mobster for checks with steps.
workflows:
  mobster:
    name: Mobster checks
    instance_type: mac_mini_m2
    max_build_duration: 60
    triggering:
      events:
        - pull_request
    environment:
      groups:
        - mobster
      vars:
        MOBSTER_BASE_BRANCH: main   # the branch your pull requests merge into
    scripts:
      - name: Install Mobster
        script: brew install uv
      - name: Prepare a simulator
        script: uvx --python 3.12 --from mobster-cli==0.4.2 mobster sim doctor --fix
      - name: Test what this PR changed
        script: uvx --python 3.12 --from mobster-cli==0.4.2 mobster ci run
    artifacts:
      - .mobster/ci/**
```

Set `MOBSTER_BASE_BRANCH` to the branch your pull requests merge into. The report, the JUnit file and the comment text are the build's artifacts. Codemagic gets no comment from Mobster: GitHub and GitLab are the hosts where `mobster ci comment` posts.

## Credentials

Launch-only checks need no model key. Set `ANTHROPIC_API_KEY` for checks that use Smart. The standalone CLI requires no Mobster account or CI token. If you supply `MOBSTER_CI_TOKEN`, `mobster ci doctor` still validates it. App-bundled commands retain their plan and token checks.

## What this runner doesn't do

A hosted Mac has no iPhone, so the checks run on simulators. To test on a phone, use [a Mac of yours](/ci/mac-runner).
