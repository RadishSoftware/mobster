The generated workflow runs the standalone `mobster-cli==0.4.2` package through uv. It needs macOS, Xcode and an iOS Simulator runtime. The Mac app is not required.

CircleCI's `macos` executor runs jobs on Macs it hosts. `mobster ci init --host circleci` writes the job. [CI](/ci) has the parts every host shares.

## Set it up

```sh
mobster ci init --host circleci
```

It writes `.circleci/config.yml`. When that file exists, it leaves it as it is and writes the job to `.mobster/hosts/config.yml` for you to merge. Then add `ANTHROPIC_API_KEY` for checks with steps as a project environment variable, commit the file and open a pull request.

```yaml .circleci/config.yml
# Mobster checks on every pull request, on a CircleCI Mac (https://docs.mobster.dev/ci/circleci).
# Add ANTHROPIC_API_KEY for checks with steps. Pick the Xcode version from CircleCI's macOS list.
version: 2.1
jobs:
  mobster:
    macos:
      xcode: "16.4.0"
    resource_class: m4pro.medium
    environment:
      MOBSTER_BASE_BRANCH: main   # the branch your pull requests merge into
    steps:
      - checkout
      - run:
          name: Install Mobster
          command: |
            brew install uv
            uvx --python 3.12 --from mobster-cli==0.4.2 mobster sim doctor --fix
      - run:
          name: Test what this PR changed
          command: |
            if [ -z "${CIRCLE_PULL_REQUEST:-}" ]; then echo "This build isn't for a pull request."; exit 0; fi
            uvx --python 3.12 --from mobster-cli==0.4.2 mobster ci run
      - store_artifacts:
          path: .mobster/ci
workflows:
  mobster:
    jobs:
      - mobster
```

Pick the Xcode version and the resource class from CircleCI's macOS list, and set `MOBSTER_BASE_BRANCH` to the branch your pull requests merge into. The report is the job's artifacts. CircleCI gets no comment from Mobster: GitHub and GitLab are the hosts where `mobster ci comment` posts.

## Credentials

Launch-only checks need no model key. Set `ANTHROPIC_API_KEY` for checks that use Smart. The standalone CLI requires no Mobster account or CI token. If you supply `MOBSTER_CI_TOKEN`, `mobster ci doctor` still validates it. App-bundled commands retain their plan and token checks.

## What this runner doesn't do

A hosted Mac has no iPhone, so the checks run on simulators. To test on a phone, use [a Mac of yours](/ci/mac-runner).
