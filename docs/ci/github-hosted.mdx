The generated workflow runs the standalone `mobster-cli==0.4.0` package through uv. It needs macOS, Xcode and an iOS Simulator runtime. The Mac app is not required.

Your pull requests are tested on `macos-15`, the arm64 macOS runner GitHub hosts. You run no Mac, and the runner needs nothing installed beforehand. [CI](/ci) has the parts every host shares: the comment, the report and the flags.

## Set it up

From your project's folder:

```sh
mobster ci init --hosted
```

It writes `.github/workflows/mobster.yml` and prints what's left: add `ANTHROPIC_API_KEY` as a repository secret for checks with steps, commit the file and open a pull request. `--force` replaces an existing file, and `--print` shows the workflow without writing it.

## The workflow

```yaml .github/workflows/mobster.yml
# Mobster checks on every pull request, on a GitHub-hosted Mac (https://docs.mobster.dev/ci/github-hosted).
# Add ANTHROPIC_API_KEY as a repository secret for checks with steps.
name: mobster
on: pull_request
permissions:
  contents: read
  pull-requests: write   # the one comment Mobster keeps up to date
concurrency:
  group: mobster-${{ github.event.pull_request.number }}
  cancel-in-progress: true
jobs:
  checks:
    runs-on: macos-15
    timeout-minutes: 60
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0   # the diff needs the base branch
      - name: Install Mobster
        id: mobster
        run: |
          brew install uv
          echo "version=0.4.0" >> "$GITHUB_OUTPUT"
          echo "xcode=$(xcodebuild -version | head -1 | tr -d ' ')" >> "$GITHUB_OUTPUT"
      - name: Cache WebDriverAgent
        uses: actions/cache@v4
        with:
          path: ~/Library/Application Support/app.mobster.desktop/wda
          key: mobster-wda-${{ runner.arch }}-${{ steps.mobster.outputs.xcode }}-${{ steps.mobster.outputs.version }}
          restore-keys: |
            mobster-wda-${{ runner.arch }}-${{ steps.mobster.outputs.xcode }}-
      - name: Prepare a simulator
        run: |
          uvx --python 3.12 --from mobster-cli==0.4.0 mobster sim doctor --fix
      - name: Test what this PR changed
        run: |
          uvx --python 3.12 --from mobster-cli==0.4.0 mobster ci run
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}   # only checks with steps use it
      - name: Upload the report
        id: upload
        if: always()
        uses: actions/upload-artifact@v4
        with:
          name: mobster-report
          path: .mobster/ci/
          include-hidden-files: true
          retention-days: 14
          if-no-files-found: ignore
      - name: Comment on the PR
        if: always()
        run: |
          uvx --python 3.12 --from mobster-cli==0.4.0 mobster ci comment
        env:
          GITHUB_TOKEN: ${{ github.token }}
          MOBSTER_ARTIFACT_URL: ${{ steps.upload.outputs.artifact-url }}
```

The cache holds the WebDriverAgent build, the slow part of a first job. Its key names the Xcode and Mobster versions, so a new Xcode or a new Mobster builds it once and every job after restores it. The simulator runtimes come with the runner's Xcode.

## Credentials

Launch-only checks need no model key. Set `ANTHROPIC_API_KEY` for checks that use Smart. The standalone CLI requires no Mobster account or CI token. If you supply `MOBSTER_CI_TOKEN`, `mobster ci doctor` still validates it. App-bundled commands retain their plan and token checks.

## What this runner doesn't do

A hosted Mac has no iPhone, so the checks run on simulators. To test on a phone, use [a Mac of yours](/ci/mac-runner).

A pull request from a fork gets no repository secrets. Checks that need a model key cannot run there without a separate trusted workflow.
