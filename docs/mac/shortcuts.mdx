Press <kbd>⌘</kbd> <kbd>/</kbd>, or choose **Help › Keyboard Shortcuts**, to see them all on the Help page's **Keyboard shortcuts** topic. **Keyboard shortcuts** in the sidebar's **Help** menu and in <kbd>⌘</kbd> <kbd>K</kbd> goes there too.

## Tasks

| Keys | What it does |
|---|---|
| <kbd>Enter</kbd> | Run the task, or send the message |
| <kbd>Shift</kbd> <kbd>Enter</kbd> | A new line in the task box |
| <kbd>⌘</kbd> <kbd>.</kbd> | Stop the running task |
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Approve the approval on screen, with its own verb (Send, Pay, Delete…), start a plan, or send every draft still open in a review. A question is never answered by a key |
| <kbd>esc</kbd> | Leave the task box, skip a plan, or stop taking control of the phone |
| <kbd>/</kbd> | At the start of the task box: your workflows, **Remember** and **Pin an app**. Type a few letters to filter, then <kbd>Enter</kbd> or <kbd>Tab</kbd>. A workflow puts its words in the box, blanks and all, to fill in and send |
| <kbd>@</kbd> | Pin an app: type a few letters, then <kbd>Enter</kbd> or <kbd>Tab</kbd>. <kbd>↑</kbd> <kbd>↓</kbd> move through the apps and <kbd>esc</kbd> closes the list |

An approval's keys answer only that approval. A key pressed in a field, a menu, a list or another dialog stays there. When several approvals are open at once, such as your task's and another agent's, click or Tab into the one you mean before you press <kbd>⌘</kbd> <kbd>Enter</kbd> or <kbd>esc</kbd>. With focus outside all of them, the keys answer none.

## Voice

In Mobster for Mac on macOS 26 or later, you can say a task instead of typing it. What you say becomes text on this Mac and goes into the task box, like anything you type. Nothing is recorded.

### Talk

- **Hold** the mic beside **Run**, or hold ⌥ Space while Mobster is in front, and say the task. Let go when you're done.
- **Tap** the mic, or tap ⌥ Space, to listen until you pause. Tap again or press Esc to stop.
- While Mobster listens, the pill above the mic reads **Listening…** and the words appear in the task box in a lighter tone until you let go.
- The words land in the task box for you to check before the task runs. With **Review before sending** off, letting go runs the task.

The first time, macOS asks for the microphone, then for speech recognition. Both prompts name Mobster.

<Note>Voice only puts words in the task box. It never answers an approval: choose **Send** or **Don't send** yourself.</Note>

### Settings › Voice

| Setting | What it does |
|---|---|
| Language | The language you speak to Mobster. **Same as this Mac** by default |
| Shortcut | Hold ⌥ Space while Mobster is in front. A quick tap listens until you pause, and Esc stops |
| Review before sending | On by default: what you say goes into the task box so you can check it. Off, the task runs when you let go |
| Test the microphone | Say something to see what Mobster hears |

### When voice can't listen

| What you see | What to do |
|---|---|
| Mobster can't hear you | Allow Mobster in System Settings › Privacy & Security › Microphone |
| Speech recognition is off | Allow Mobster in System Settings › Privacy & Security › Speech Recognition |
| Voice isn't available for [language] on this Mac | Choose another language in Settings › Voice |
| Getting speech ready on this Mac (one time) | macOS is getting its speech model. You can talk to Mobster when it's done |
| Mobster can't use the microphone | Another app may be using it. Close that app, or check System Settings › Sound |
| Voice needs macOS 26 or later | Voice isn't available on this Mac. Type the task instead |

Voice is in Mobster for Mac only, not in the CLI.

## Moving around

| Keys | What it does |
|---|---|
| <kbd>⌘</kbd> <kbd>K</kbd> | Search conversations, tasks, apps and Settings sections. It opens on the page's own commands first, under the page's name: **New workflow** and **Run a workflow…** on Workflows, **Add a device** on Devices, **Add a project** on Projects, **Run workflow here…** in a conversation. **Run a workflow…** works from any page. Typing "models" or "approvals" lists the Settings section that holds them. The last row, **Ask Mobster**, puts what you typed in the task box for you to send |
| <kbd>⌘</kbd> <kbd>N</kbd> | New task |
| <kbd>⌘</kbd> <kbd>1</kbd> | Home: the task box, or the task you have open |
| <kbd>⌘</kbd> <kbd>2</kbd> | Workflows |
| <kbd>⌘</kbd> <kbd>3</kbd> | Apps |
| <kbd>⌘</kbd> <kbd>4</kbd> | Devices |
| <kbd>⌘</kbd> <kbd>5</kbd> | Projects |
| <kbd>⌘</kbd> <kbd>6</kbd> | Profiles |
| <kbd>⌘</kbd> <kbd>7</kbd> | Queue |
| <kbd>⌘</kbd> <kbd>8</kbd> | Memory |
| <kbd>⌘</kbd> <kbd>9</kbd> | Connectors |
| <kbd>⌘</kbd> <kbd>[</kbd> and <kbd>⌘</kbd> <kbd>]</kbd> | Back and forward through the pages you went to |
| <kbd>⌘</kbd> <kbd>,</kbd> | Settings |
| <kbd>⌃</kbd> <kbd>⌘</kbd> <kbd>S</kbd> | Show or hide the sidebar |
| <kbd>⌘</kbd> <kbd>/</kbd> | Keyboard shortcuts |
| <kbd>esc</kbd> | Back, on every page that has a **Back** or **Cancel**: Settings, Help, Add a device, Add a project, Send feedback, a workflow's canvas and an app's page. In a field, the first <kbd>esc</kbd> leaves the field and keeps what you typed; the next one goes back. An open menu or dialog closes first |
| <kbd>⌘</kbd> <kbd>Q</kbd> | Quit Mobster. Closing the window keeps it running for schedules |

## Lists: All conversations, Workflows and Apps

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd>, or <kbd>J</kbd> <kbd>K</kbd> | Move through the list |
| <kbd>/</kbd> or <kbd>⌘</kbd> <kbd>F</kbd> | Search the list |
| <kbd>Delete</kbd> | Delete the workflow in focus |
| <kbd>esc</kbd> | Clear the search |

Right-click (or two-finger click) a conversation in the sidebar, a project, a profile or a device to open its **⋯** menu.

## Setup

| Keys | What it does |
|---|---|
| <kbd>Enter</kbd> | The screen's main button |
| <kbd>⌘</kbd> <kbd>[</kbd> | Back |
| <kbd>⌘</kbd> <kbd>]</kbd> | Skip a step that is optional, such as waiting for Xcode to download |
