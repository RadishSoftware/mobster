## Tasks

| Keys | What it does |
|---|---|
| <kbd>Enter</kbd> | Run the task, or send the message |
| <kbd>Shift</kbd> <kbd>Enter</kbd> | A new line in the task box |
| <kbd>⌘</kbd> <kbd>.</kbd> | Stop the running task |
| <kbd>⌘</kbd> <kbd>Enter</kbd> | Approve the approval on screen, with its own verb (Send, Pay, Delete…). A question is never answered by a key |
| <kbd>Esc</kbd> | Leave the task box, or stop taking control of the phone |

## Voice

| Keys | What it does |
|---|---|
| Hold <kbd>⌥</kbd> <kbd>Space</kbd> | Talk while you hold it. The words go into the task box |
| Tap <kbd>⌥</kbd> <kbd>Space</kbd> | Listen until you pause |
| <kbd>Esc</kbd> | Stop listening |

## Moving around

| Keys | What it does |
|---|---|
| <kbd>⌘</kbd> <kbd>K</kbd> | Search conversations, tasks and apps |
| <kbd>⌘</kbd> <kbd>N</kbd> | New task |
| <kbd>⌘</kbd> <kbd>1</kbd> | The task page |
| <kbd>⌘</kbd> <kbd>2</kbd> | History |
| <kbd>⌘</kbd> <kbd>3</kbd> | Workflows |
| <kbd>⌘</kbd> <kbd>4</kbd> | Apps |
| <kbd>⌘</kbd> <kbd>,</kbd> | Settings |
| <kbd>⌘</kbd> <kbd>Q</kbd> | Quit Mobster. Closing the window keeps it running for schedules |

## Lists: History, Workflows and Apps

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd>, or <kbd>J</kbd> <kbd>K</kbd> | Move through the list |
| <kbd>/</kbd> or <kbd>⌘</kbd> <kbd>F</kbd> | Search the list |
| <kbd>Delete</kbd> | Delete the item in focus |
| <kbd>Esc</kbd> | Clear the search |

## Setup

| Keys | What it does |
|---|---|
| <kbd>Enter</kbd> | The screen's main button |
| <kbd>⌘</kbd> <kbd>[</kbd> | Back |
| <kbd>⌘</kbd> <kbd>]</kbd> | Skip a step that is optional, such as waiting for Xcode to download |
