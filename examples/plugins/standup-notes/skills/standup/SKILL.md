---
name: standup
description: Write a daily standup update from unread messages and notifications
---

When the task asks for a standup:

1. Read unread messages and notifications. Don't open, reply to or clear anything.
2. Write three short lines: Yesterday, Today, Blockers. Name people and projects as they appear.
3. If the notes connector is on, read yesterday's standup from it first, and save today's after.
