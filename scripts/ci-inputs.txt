# What each local CI stage reads (scripts/ci-local.sh, scripts/ci_inputs.py). A stage is skipped when every path
# listed for it here, and everything no line names, is byte for byte what an earlier green run of the stage saw.
#
#   path   stage stage ...     these stages read path (a file, or a folder and what is in it)
#   path   stage=exists        the stage checks that path is there and never reads what is in it
#   path   -                   no stage reads it
#
# The most specific line wins, so a line for a file or folder inside one with its own line replaces that line for the
# inside. A word with * or ? matches one path segment (mobile_agent/swift/helper_*.swift). A path no line covers is read by
# every stage: a new file in a folder keeps the folder's line, and a new top-level folder runs every stage until a line
# classifies it. mobile_agent/tests/test_ci_inputs.py fails for a top-level path with no line of its own.
#
# A line is a claim that the other stages never open the path. A stage that reads a path its line leaves out would pass
# on a cache hit with a stale answer, so when you change what a stage reads (a test that opens ../, an include_str!, a
# new tool) add the stage here in the same change. The stages: backend (scripts/ci_backend.py, the whole Python suite),
# dashboard (its build ends with scripts/perf_budget.py bundle and dashboard/perf/frames.mjs), design (scripts/design-checks: the app's, the site's,
# Remote's and the license pages' styles and words, the native shell's words, the docs and the CLI's help), desktop
# (cargo fmt, clippy, test), helpers (swiftc -typecheck), editors (editors/vscode: tsc and its node:test suite), license (services/license-api), lint (ruff, the site's ESLint), perf (scripts/perf_budget.py agent: it imports
# and starts the server, so it reads everything backend reads), relay, site, versions (desktop/scripts/check-version.py).
#
# How the lines were checked (14 Oct 2026): each stage below ran in a commit of the repository with every path its lines
# leave out deleted (a path read as =exists keeps one placeholder file), and passed with the test count of the full tree:
# backend 5,273 tests in 315 modules, dashboard 2,470 tests in 207 files, license 187, relay 113, site 123 (2 skipped), lint,
# helpers and versions clean. The desktop stage was not run that way: a cold cargo build needs about 6 GiB, and the Mac had
# 11 GiB free. test_ci_inputs.py instead lists every include_str!, include_bytes! and ../ path that leaves desktop/ or
# another stage's folder, and fails when one is missing here.
